# Rubik's Cube Game

I created this as a project for **ISC 3222 - Symbolic and Numerical Computations** at Florida State University.

## How to Run

To run the game, run the main file with all the other files in the same directory.

You can click on the start button to scramble the cube, but you will have to click somewhere else on the screen right after before you can start typing the keybinds.

## Keybinds

- **Spacebar** — Scramble the cube (can be used as an alternative to pressing the start button)
- **F / J** — Turn the upper layer CCW / CW
- **E / D** — Turn the left layer CCW / CW
- **K / I** — Turn the right layer CCW / CW
- **G / H** — Turn the front layer CCW / CW
- **O / W** — Turn the back layer CCW / CW
- **L / S** — Turn the down layer CCW / CW
- **Enter** — Stop the timer
